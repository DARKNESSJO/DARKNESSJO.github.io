About

关于我

一点背景，以及我为什么喜欢写代码。

2019 年，我用一段 HTML 和 CSS 做出了人生第一个网页——那是一个丑得离谱的 个人主页，但它让我第一次意识到：屏幕上的东西，是可以被自己创造的。

如今我是一名前端工程师，日常在做的事情包括：搭建组件库、优化首屏性能、 和设计师一起抠那 2px 的对齐，以及在深夜重构一个早就该重构的模块。

我喜欢「把复杂变简单」这件事。好的界面不该让人注意到它的存在， 它只是静静地，把事情办好。
